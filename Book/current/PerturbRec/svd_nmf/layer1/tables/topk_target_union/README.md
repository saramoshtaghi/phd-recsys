# Top-15 / Top-25 / Top-35 target-title analysis

All three list lengths are prefixes of one stable, unseen-only Top-35 ranking per real user. No model was retrained. The same 53,424 real users and saved factors are used as in the previous Top-35 analysis.

Bars show mean target-book counts only. Under-bar rows show union size, repeat percentage (100*(1-U/T)), and most frequent title user reach. Union repetition is not pairwise recommendation overlap. Genre membership is inclusive for multi-genre books; unknown is not a genre category in the analysis.

Top-35 totals and unions exactly match the prior output. Top-15 means match available controlled references. NMF-Thriller checkpoints above 500 have historical negative factors and are explicitly hatched, not treated as validated nonnegative fits.

The two existing final_results files retain their top35_union_powerpoint names, but now include all three list lengths. Cached per-condition JSON files permit resuming. The complete summary contains 156 rows.
